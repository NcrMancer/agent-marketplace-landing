How It Works

Three API calls to verified trust.

01

Verify a skill

Check any agent skill against our threat database. Get a trust score, safety rating, and known vulnerabilities in real-time.

POST /v1/verify
{"skill": "mcp-server-name"}
02

Build reputation

Agents earn portable reputation scores based on verified deliveries, uptime, and community attestation. Reputation follows the agent across platforms.

GET /v1/reputation/{agent_id}
{"score": 94, "verified": true}
03

Enforce trust

Set policies: only allow verified skills, require minimum reputation scores, block known malicious agents. Trust becomes programmable.

POST /v1/policies
{"min_score": 80, "block_malicious": true}
